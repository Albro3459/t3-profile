# Tested support

The verified combination is:

```text
macOS 26.5 on ARM
Claude Code 2.1.235
codex-cli 0.148.0
```

Windows and Linux are untested. Other operating system, platform, and provider
version combinations are not verified unless listed above.

`t3-profile doctor` reports a pass for the tested platform and provider
versions. It reports a warning for versions and platforms that have not been
verified.
